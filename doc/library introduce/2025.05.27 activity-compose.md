activity-compose

`androidx.activity:activity-compose` は、Jetpack Compose と Android の `Activity` を統合するためのコアライブラリです。**はい、現在でも使用されており、Compose UI を使用するすべての Android アプリケーションにとって不可欠なライブラリです。**

------

### `activity-compose` の役割

このライブラリは主に、`ComponentActivity` の拡張関数である **`setContent`** を提供します。これは、`Activity` 内で Compose UI を起動するための主要な方法です。

- `setContent` 拡張関数:

   この関数を使用すると、

  ```
  ComponentActivity
  ```

   内で Compose UI を直接定義し、表示することができます。

  ```
  ComposeView
  ```

   のセットアップと Compose のコンポジションライフサイクルの管理を担当し、

  ```
  Activity
  ```

   のライフサイクルと同期させます。

  Kotlin

  ```
  class MyComposeActivity : ComponentActivity() {
      override fun onCreate(savedInstanceState: Bundle?) {
          super.onCreate(savedInstanceState)
          setContent {
              // ここに Jetpack Compose UI を記述
              MyComposableScreen()
          }
      }
  }
  ```

- Activity 関連の Compose API:

  ```
  activity-compose
  ```

   には、一般的な Activity 関連のタスクを処理するための他の重要な Compose フレンドリーな API も含まれています。例えば、以下のようなものがあります。

  - **`rememberLauncherForActivityResult()`:** コンポーザブル内で Activity を起動し、結果を取得できるようにします（例：ギャラリーから画像を選択したり、実行時パーミッションを要求したり）。
  - **`BackHandler`:** コンポーザブル内でシステム戻るボタンのイベントを処理し、デフォルトの動作を上書きするために使用します。
  - **`LocalActivity` (Activity 1.9.0 以降):** 現在の `Activity` インスタンスの `CompositionLocal` を提供します。これにより、コンポーザブル内で `Activity` に安全にアクセスでき、`LocalContext.current as Activity` のような安全でない型キャストを行う必要がありません（ただし、`ComponentActivity` の場合は通常安全です）。

------

### なぜ重要なのか？

Jetpack Compose のシングル Activity アーキテクチャの推奨では、`activity-compose` は Compose UI を Android アプリケーションに導入するための鍵となります。これにより、Activity と Compose 間のインタラクションが簡素化され、Activity 内で Compose ドリブンの UI 全体を構築することが非常に直感的になります。

### 最新バージョンの取得方法

直接バージョン番号を指定することもできますが、**Compose BOM と一緒に使用することを強くお勧めします**。これにより、すべての Compose 関連ライブラリの互換性が保証されます。

Gradle

```
dependencies {
    // Compose BOM をインポートし、Compose ライブラリのバージョン互換性を管理
    implementation platform("androidx.compose:compose-bom:<latest_compose_bom_version>") // 例: 2025.04.01

    // Activity Compose ライブラリ
    // BOM を使用する場合、通常バージョン番号は指定不要
    implementation "androidx.activity:activity-compose"
}
```

特定のバージョン履歴とリリース情報については、以下を参照してください。

- [AndroidX Activity のリリースノート](https://developer.android.com/jetpack/androidx/releases/activity)
- [Maven Central: androidx.activity:activity-compose](https://mvnrepository.com/artifact/androidx.activity/activity-compose)

------

### まとめ

`androidx.activity:activity-compose` は、Jetpack Compose 開発において不可欠なライブラリです。Compose UI を `Activity` に組み込み、Activity 関連のイベントを処理するための便利な Compose API を提供します。
