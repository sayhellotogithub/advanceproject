`android.desugar.jdk.libs` 是 Android Gradle Plugin (AGP) 用来提供 Java 8+ API（如 `java.time`、`java.util.stream` 等）支持的一个关键库，即使你的应用运行在旧版本的 Android 设备上（例如 API 级别 24 以下）。

**它的作用：**

在 Android 开发中，默认情况下，JVM 字节码会被转换为 Dalvik/ART 字节码。但是，Dalvik/ART 运行时环境不完全支持所有最新的 Java API，特别是 Java 8 及更高版本引入的新特性。

`android.desugar.jdk.libs` 库就是为了解决这个问题。它通过**“Desugaring”（语法糖去除）**的过程，将这些新的 Java API 调用转换为可以在旧 Android 设备上运行的代码。它通过以下方式实现：

- **API 接口和实现：** 提供了缺失的 Java API 接口和它们的实现，这些实现是针对旧 Android 版本重新编译和优化过的。
- **字节码转换：** 在编译时，AGP 会检测代码中对这些新 Java API 的使用，并将其转换为对 `android.desugar.jdk.libs` 中提供的实现类的调用。

**为什么仍然需要它？**

尽管现代 Android 设备普遍运行在较新的 Android 版本上，但为了**确保你的应用能在更广泛的设备上兼容运行**，尤其是那些 API 级别较低的设备，`android.desugar.jdk.libs` 仍然是必不可少的。

例如，如果你在应用中使用了 `java.time.LocalDate` 或 `java.util.stream.Collectors`，而目标设备是 API 级别 21 (Android 5.0)，那么如果没有 `android.desugar.jdk.libs`，你的应用可能会在运行时崩溃。

**如何配置和使用：**

你需要在模块的 `build.gradle` 文件中添加 `coreLibraryDesugaring` 依赖，并配置 Java 版本。

Gradle

```
android {
    compileOptions {
        // 配置你的 Java 版本，通常是 Java 8 或更高
        sourceCompatibility JavaVersion.VERSION_1_8
        targetCompatibility JavaVersion.VERSION_1_8

        // 启用 desugaring
        // 如果 targetSdkVersion >= 34，则不需要这个，因为大部分新的API都在Android 14+中被平台直接支持了。
        // 但为了兼容旧版本，通常仍建议启用。
        isCoreLibraryDesugaringEnabled = true
    }
}

dependencies {
    // ... 其他依赖

    // 添加 desugaring 库的依赖
    // 请替换 <latest_version> 为最新版本
    coreLibraryDesugaring 'com.android.tools:desugar_jdk_libs:2.0.4' // 截至 2025 年 5 月，这是最新稳定版
}
```

**最新版本：**

截至 **2025 年 5 月 27 日**，`com.android.tools:desugar_jdk_libs` 的最新稳定版本是 **`2.0.4`**。

你可以通过以下方式确认最新版本：

- Maven Central：搜索 `desugar_jdk_libs`。
- Android Gradle Plugin 发布说明：这些库的版本通常与 AGP 的版本同步更新。

**总结：**

`android.desugar.jdk.libs` 仍然是一个非常重要的库，它允许 Android 开发者在旧版本的设备上使用现代 Java API。为了确保广泛的兼容性，它仍然是 Android 项目中推荐的配置。
