metrics-performance

`androidx.metrics:metrics-performance` は、Jetpack の **Compose Metrics ライブラリ**の一部であり、Android アプリケーション、特に Jetpack Compose で構築された UI の**パフォーマンスに関する詳細なメトリクス (測定値)** を収集するために設計されたライブラリです。

これは主に、開発者や自動テスト (特に Macrobenchmark) が、UI の**フレームレンダリングパフォーマンス**をより深く理解し、ボトルネックを特定し、カクつき (jank) を減らすためのツールとして使用されます。

### その役割と重要性

このライブラリは、単に UI のフレームレートを測定するだけでなく、より詳細な情報を提供することで、パフォーマンスの問題の根本原因を特定するのに役立ちます。

主な機能と提供するメトリクスは以下の通りです。

1. **`FrameData` の収集:**
   - UI の各フレームについて、以下の詳細なタイムスタンプ情報を収集します。
     - **`FrameStart`**: フレームの描画が開始された時刻。
     - **`FrameReady`**: コンポーズとレイアウトの処理が完了し、フレームが描画可能になった時刻。
     - **`FrameEnd`**: フレームが画面にレンダリングされた時刻。
   - これらのタイムスタンプを分析することで、以下の重要な指標を計算できます。
     - **コンポーズ/レイアウト時間:** `FrameReady - FrameStart` (Compose がどれだけ素早く UI ツリーを準備できたか)
     - **レンダリング時間:** `FrameEnd - FrameReady` (UI がどれだけ素早く画面に描画されたか)
     - **総フレーム時間:** `FrameEnd - FrameStart` (フレーム全体の処理時間)
2. **カクつき (Jank) の特定:**
   - 期待されるフレームレート (例: 60fps で 16.67ms) を超えるフレーム時間を「カクつき」として識別し、その発生頻度と深刻度を把握するのに役立ちます。
   - 具体的な原因 (Compose が遅いのか、それともシステム側のレンダリングが遅いのか) を切り分けるための手がかりを提供します。
3. **自動化されたテストへの統合:**
   - 特に `benchmark-macro` (Macrobenchmark) と組み合わせて使用されることが多く、自動化された UI シナリオ (スクロールなど) のパフォーマンスメトリクスを収集し、パフォーマンスの回帰テストに利用されます。
   - CI/CD パイプラインに組み込むことで、コード変更が UI パフォーマンスに与える影響を継続的に監視できます。

### `androidx.metrics:metrics-performance` と Jetpack Compose

Jetpack Compose は Declarative UI であるため、UI のパフォーマンス測定は従来の View システムとは異なるアプローチが必要になります。`metrics-performance` は、Compose の内部動作に深く統合されており、Compose UI のフレームパイプラインから直接データを収集するため、非常に正確で有用なパフォーマンスインサイトを提供します。

開発中に UI のカクつきを感じた場合や、特定の Composable のパフォーマンスを最適化したい場合に、このライブラリを組み合わせてプロファイリングを行うことで、具体的な数値データに基づいた改善策を検討できるようになります。

### 最新バージョン

Maven Central および Android Developers の公式リリースノートによると、**2025年5月27日**現在、`androidx.metrics:metrics-performance` の最新安定バージョンは **`1.0.0-alpha01`** です。

これはまだアルファ版であり、API が変更される可能性があることを示唆しています。しかし、パフォーマンス測定というニッチで重要な領域をカバーするため、現時点ではこれが最も進んだ解決策です。

### 依存関係の追加方法

プロジェクトのモジュールレベルの `build.gradle` ファイルに以下を追加します。通常、`debugImplementation` または `androidTestImplementation` として追加し、本番ビルドには含めません。

Gradle

```
dependencies {
    // パフォーマンス測定用のライブラリ (通常はデバッグビルドまたはテストビルドのみ)
    debugImplementation 'androidx.metrics:metrics-performance:1.0.0-alpha01'
    androidTestImplementation 'androidx.metrics:metrics-performance:1.0.0-alpha01'

    // 他の依存関係...
}
```

### 使用例 (コードスニペットの概要)

通常、このライブラリは直接コードで `FrameData` を収集するよりも、Android Studio Profiler や Macrobenchmark を介してその機能を活用することが多いです。

しかし、もしコードから直接利用したい場合、例えばカスタムプロファイリングツールを作成するような場合は、`PerformanceMetricsState` を使用する形になります。

Kotlin

```
// 例: 特定の Composable のレンダリングパフォーマンスを測定 (高度なケース)
@Composable
fun MyPerformanceMeasuredComposable() {
    val context = LocalContext.current
    val performanceMetricsState = remember {
        // PerformanceMetricsState を取得し、ライフサイクルに応じて管理
        PerformanceMetricsState.createAndInstall(context.applicationContext)
    }

    DisposableEffect(Unit) {
        val listener = FrameData.Listener { frameData ->
            // ここで frameData を処理し、ログ出力や分析を行う
            // frameData.frameStartNanos, frameData.frameReadyNanos, frameData.frameEndNanos など
            Log.d("PerformanceMetrics", "Frame data: $frameData")
        }
        performanceMetricsState.addStateListener(listener)

        onDispose {
            performanceMetricsState.removeStateListener(listener)
        }
    }

    // UI コンテンツ
    Text("Measuring Performance")
}
```

### まとめ

`androidx.metrics:metrics-performance` は、Jetpack Compose アプリケーションの UI パフォーマンス、特にフレームレンダリングのメトリクスを詳細に測定するための専門的なライブラリです。まだアルファ版ですが、UI のカクつきを特定し、ユーザー体験を最適化するために非常に有望で重要なツールです。主にプロファイリングや自動ベンチマークテストの文脈で使用されます。
