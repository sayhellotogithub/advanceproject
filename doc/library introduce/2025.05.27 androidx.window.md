androidx.window

`ndroidx.window` は、Android アプリケーションが**様々なフォームファクターやウィンドウの状態に効果的に適応**できるようにするための Jetpack ライブラリ群です。特に、**折りたたみ式デバイス (foldables)** や**複数のディスプレイ**を持つデバイス、**大きな画面デバイス (large screens)** でのユーザー体験を最適化することを目的としています。

このライブラリは、標準の Android フレームワーク API では利用できない、または一貫性のない方法でしか利用できない、ウィンドウイング機能やデバイスの状態に関する情報を提供します。

### その役割と重要性

現代の Android デバイスの多様化（スマートフォン、タブレット、折りたたみ式、デュアルスクリーンなど）に対応するために、`androidx.window` は非常に重要です。

主な役割と重要性は以下の通りです。

1. **折りたたみ式デバイスのサポート:**
   - **`FoldingFeature`:** デバイスのヒンジ（折り目）や折りたたみ位置に関する情報を提供します。これにより、アプリはこの折り目を考慮したレイアウトを設計し、コンテンツがヒンジによって隠れたり分割されたりしないように調整できます。
   - **`WindowLayoutInfo`:** 現在のウィンドウに関するレイアウト情報（例: 折りたたみの特徴、ディスプレイの分割情報など）を `Flow` として提供します。
2. **マルチディスプレイ/マルチウィンドウ対応:**
   - デバイスが複数のディスプレイを持っている場合や、アプリがマルチウィンドウモードで実行されている場合に、各ウィンドウやディスプレイの特性に関する情報を提供します。
   - 特定の画面領域や表示モードに合わせて UI を調整するのに役立ちます。
3. **大画面デバイスでの最適化:**
   - タブレットなどの大画面デバイスで、アプリが単に拡大表示されるだけでなく、より効果的にスペースを利用するためのガイダンスやツールを提供します（例: リスト/詳細レイアウトの最適化）。
4. **互換性:**
   - 古い Android バージョンでも、可能であれば新しいウィンドウ機能を利用できるように、後方互換性を提供します。
   - デバイスメーカーごとに異なる実装を抽象化し、一貫した API を提供します。

### `androidx.window` の主要モジュール

- **`androidx.window:window`**:
  - デバイスのディスプレイとウィンドウに関する情報（例: `WindowMetrics`、`WindowLayoutInfo`）を提供するコアモジュールです。
  - `FoldingFeature` や `DisplayFeature` といった、折りたたみや複数ディスプレイの情報を扱います。
- **`androidx.window:window-testing`**:
  - ウィンドウ情報をテストするためのユーティリティが含まれています。

### `androidx.window` と Jetpack Compose

Jetpack Compose は Declarative UI であるため、`androidx.window` からのレイアウト情報を簡単に利用して、適応型 UI を構築できます。

- `WindowLayoutInfo` の監視:

  ```
  WindowLayoutInfo
  ```

   は 

  ```
  Flow
  ```

   として公開されるため、Compose の 

  ```
  collectAsState()
  ```

   を使用してその変更を監視し、リアルタイムで UI レイアウトを調整できます。

  Kotlin

  ```
  val windowMetricsCalculator = remember { WindowMetricsCalculator.getOrCreate() }
  val windowLayoutInfo = remember(windowMetricsCalculator) {
      windowMetricsCalculator.computeCurrentWindowMetrics(context.get())
          .windowLayoutInfo(context.get()) // `get()` は Context を提供するヘルパー
  }.collectAsState(initial = WindowLayoutInfo(emptyList())).value
  
  val foldingFeature = windowLayoutInfo.displayFeatures.filterIsInstance<FoldingFeature>().firstOrNull()
  
  // foldingFeature の状態に基づいて UI を調整
  if (foldingFeature != null && foldingFeature.isSeparating) {
      // デバイスが折りたたまれて分割されている場合のレイアウト
  } else {
      // 通常のレイアウト
  }
  ```

- **適応型コンポーネントとの連携:** `material3-adaptive` (特に `material3-adaptive-layout` や `material3-adaptive-navigation-suite`) は、`androidx.window` からの情報（ウィンドウサイズクラスなど）を利用して、より高レベルな適応型レイアウトの決定をサポートします。

### 最新バージョン

Maven Central および Android Developers の公式リリースノートによると、**2025年5月27日**現在、`androidx.window` の最新安定バージョンは以下の通りです。

- **`androidx.window:window`**: `1.3.0`
- **`androidx.window:window-core`**: `1.3.0` (内部的な依存)
- **`androidx.window:window-java`**: `1.3.0` (Java 開発者向け)
- **`androidx.window:window-kotlin`**: `1.3.0` (Kotlin 開発者向け、Kotlin 拡張を含む)
- **`androidx.window:window-rxjava2` / `window-rxjava3`**: `1.3.0` (RxJava との統合)

これらのライブラリは頻繁に更新される可能性があるため、常に [Android Developers の Jetpack Window リリースノート](https://developer.android.com/jetpack/androidx/releases/window) を確認して最新の情報を入手することをお勧めします。

### 依存関係の追加方法

プロジェクトのモジュールレベルの `build.gradle` ファイルに以下を追加します。通常、Kotlin アプリケーションでは `window-kotlin` を追加します。

Gradle

```
dependencies {
    // 最新の安定版を推奨
    implementation 'androidx.window:window-kotlin:1.3.0'

    // テストが必要な場合 (通常は androidTestImplementation)
    // androidTestImplementation 'androidx.window:window-testing:1.3.0'

    // 他の依存関係...
}
```

### まとめ

`androidx.window` は、Android デバイスの多様化（特に折りたたみ式デバイスや大画面デバイス）に対応し、アプリがさまざまなウィンドウ状態にシームレスに適応できるようにするための非常に重要なライブラリです。Jetpack Compose と組み合わせることで、動的で適応性のある UI を効率的に構築することが可能になります。現代の Android アプリケーション開発では、このライブラリの利用がますます重要になっています。
