splashscreen

`androidx.core:core-splashscreen` は、Android 12 (API レベル 31) 以降で導入された**新しいスプラッシュスクリーン API** を、古い Android バージョンでも互換性のある形で利用できるようにするための AndroidX ライブラリです。

Android 12 以降のデバイスでは、システムがスプラッシュスクリーンを自動的に生成・表示するようになりました。このライブラリは、この新しいシステムのスプラッシュスクリーンの外観や動作をカスタマイズし、さらに古い Android バージョン (API レベル 23 以降) でも同様のスプラッシュスクリーン体験を提供するためのヘルパーを提供します。

### その役割と重要性

このライブラリの主な役割は、**アプリの起動時のユーザー体験を向上させること**です。

1. **統一されたスプラッシュスクリーン体験:** Android 12 以降のデバイスでは、システムが自動でスプラッシュスクリーンを表示します。このライブラリを使用すると、そのシステムのスプラッシュスクリーンをカスタマイズできます。さらに、Android 12 より古いデバイスでも、同様のカスタマイズされたスプラッシュスクリーンを**エミュレート**して表示できるため、全てのユーザーに一貫した起動体験を提供できます。
2. **ブランディングの強化:** アイコン、背景色、アニメーションなどをカスタマイズすることで、アプリの起動時にブランドイメージを効果的に表示できます。
3. **シームレスな移行:** スプラッシュスクリーンからアプリの最初の画面への遷移をスムーズにし、ユーザーが待っている間の印象を良くします。特に、アプリのコンテンツが完全にロードされるまでの時間を視覚的に埋めるのに役立ちます。
4. **互換性:** `minSdkVersion` が古いアプリでも、Android 12 の新しいスプラッシュスクリーン機能を活用できます。

### 典型的な使用例

- アプリ起動時に、アプリのロゴやブランドカラーを表示する。
- データ読み込み中など、アプリの準備が完了するまでの間にユーザーを楽しませる。

### `core-splashscreen` の実装フロー

1. **テーマの設定:** アプリのテーマにスプラッシュスクリーン用のテーマ（例: `Theme.App.SplashScreen`）を定義し、アプリの最初の Activity に適用します。このテーマで、スプラッシュスクリーンの背景色、アイコン、アニメーションなどを指定します。

2. **インストール:** `installSplashScreen()` メソッドを Activity の `onCreate()` の `super.onCreate()` の**前**に呼び出します。これにより、スプラッシュスクリーンが設定されます。

3. コンテンツの準備:

    アプリの初回起動時にコンテンツをロードするなどの処理が必要な場合、その処理が完了するまでスプラッシュスクリーンを画面に表示し続けるように設定できます。

   Kotlin

   ```
   class MyMainActivity : ComponentActivity() {
       override fun onCreate(savedInstanceState: Bundle?) {
           // super.onCreate() の前にスプラッシュスクリーンを設定
           val splashScreen = installSplashScreen()
   
           super.onCreate(savedInstanceState)
   
           // コンテンツの準備が完了するまでスプラッシュスクリーンを維持する
           // ここでデータロードなどの非同期処理を行い、準備が完了したら splashScreen.setKeepOnScreenCondition { false } を呼び出す
           var keepSplashOnScreen = true
           lifecycleScope.launch {
               delay(3000) // 例: 3秒間スプラッシュスクリーンを表示
               keepSplashOnScreen = false
           }
   
           splashScreen.setKeepOnScreenCondition { keepSplashOnScreen }
   
           setContent {
               MyApplicationTheme {
                   // アプリのメインコンテンツ
                   Text("Welcome to My App!")
               }
           }
       }
   }
   ```

### 最新バージョン

Maven Central および Android Developers の公式リリースノートによると、**2025年5月27日**現在、`androidx.core:core-splashscreen` の最新安定バージョンは **`1.0.1`** です。

### まとめ

`androidx.core:core-splashscreen` は、Android 12 以降の新しいシステムスプラッシュスクリーン API を活用しつつ、古い Android バージョンにも一貫したスプラッシュスクリーン体験を提供するための重要なライブラリです。アプリの起動時のブランディングとユーザー体験を向上させるために広く利用されています。
