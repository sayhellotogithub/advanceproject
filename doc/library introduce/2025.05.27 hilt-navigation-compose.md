hilt-navigation-compose

`androidx.hilt:hilt-navigation-compose` は、**Jetpack Compose で Dagger Hilt を使用して、ナビゲーショングラフ内の Composable ごとに ViewModel を注入する**ためのライブラリです。

通常、Hilt を使用して Compose アプリで ViewModel を取得する場合、`@HiltViewModel` アノテーションを付けた ViewModel を `hiltViewModel()` 関数で取得します。

Kotlin

```
@Composable
fun MyScreen(
    viewModel: MyViewModel = hiltViewModel()
) {
    // ...
}
```

しかし、Jetpack Navigation for Compose を使用して複数の画面を管理する場合、特定の `NavGraph` のスコープに ViewModel を関連付けたり、異なるルート間で同じ ViewModel インスタンスを共有したりしたいことがあります。`hilt-navigation-compose` は、このニーズに応えるための機能を提供します。

### その役割と重要性

このライブラリは、Hilt と Navigation for Compose を連携させる際に、特に以下のシナリオで役立ちます。

1. **ナビゲーショングラフのスコープの ViewModel:**
   - デフォルトの `hiltViewModel()` は、現在の `NavBackStackEntry` (現在の画面) に ViewModel をスコープします。
   - `hilt-navigation-compose` は、**ナビゲーショングラフ全体にスコープされた ViewModel** を提供できます。これは、あるナビゲーショングラフ内の複数の Composable で同じ ViewModel インスタンスを共有したい場合に便利です。例えば、ウィザード形式のフロー全体で同じ ViewModel を共有して状態を保持するようなケースです。
2. **`NavBackStackEntry` を DI に提供:**
   - Hilt の依存性注入システムで、現在の `NavBackStackEntry` を注入可能にすることで、`NavBackStackEntry` に紐付けられた特定のデータ (例: 渡された引数) を ViewModel の構築時に利用できるようになります。これにより、より柔軟な ViewModel のファクトリ作成が可能になります。

### 典型的な使用例

`hilt-navigation-compose` が提供する主な関数は `hiltViewModel()` ですが、特に**グラフスコープの ViewModel** を取得したい場合に、このライブラリの真価が発揮されます。

例: 特定のグラフにスコープされた ViewModel を取得する

Kotlin

```
// 例: user_flow_graph というグラフIDのスコープで ViewModel を取得
@Composable
fun NavGraphBuilder.userFlowGraph(navController: NavHostController) {
    navigation(startDestination = "step1", route = "user_flow") {
        composable("step1") { backStackEntry ->
            // この ViewModel は "user_flow" グラフ全体で共有される
            val sharedViewModel: UserFlowViewModel = hiltViewModel(backStackEntry = backStackEntry)
            // ...
        }
        composable("step2") { backStackEntry ->
            val sharedViewModel: UserFlowViewModel = hiltViewModel(backStackEntry = backStackEntry)
            // ...
        }
    }
}
```

**注意:** 最新の `androidx.navigation:navigation-compose` では、`hiltViewModel()` に `backStackEntry` パラメータを渡すことで、特定の `NavBackStackEntry` (例: 親グラフの `NavBackStackEntry`) に ViewModel をスコープできるようになっています。これは、`hilt-navigation-compose` の提供する機能と重複または吸収されている可能性があります。

### `hilt-navigation-compose` の現状と代替

- **`hilt-navigation-compose` は現在も使用されています。**
- ただし、`androidx.navigation:navigation-compose` ライブラリ自体が進化しており、`hilt-navigation-compose` の機能の一部は `navigation-compose` 自体に吸収されつつあるかもしれません。
- 例えば、**ナビゲーショングラフスコープのViewModel**については、`androidx.navigation:navigation-compose` の最近のバージョンで提供される `hiltViewModel(navController.getViewModelStoreOwner(R.id.graph_id))` のような機能を使用して実現できる場合があります。

したがって、このライブラリを追加する前に、使用している `navigation-compose` のバージョンで、その目的の機能がすでに提供されていないか確認することをお勧めします。もし提供されている場合は、余分な依存関係を追加せずに済む可能性があります。

### 最新バージョン

Maven Central および Android Developers の公式リリースノートによると、**2025年5月27日**現在、`androidx.hilt:hilt-navigation-compose` の最新安定バージョンは **`1.2.0`** です。

また、`1.3.0-alpha01` などの新しいプレリリース版も存在します。

### 依存関係の追加方法

プロジェクトのモジュールレベルの `build.gradle` ファイルに以下を追加します。

Gradle

```
dependencies {
    // Hilt の依存関係
    implementation 'com.google.dagger:hilt-android:2.51.1' // 最新バージョンを確認
    kapt 'com.google.dagger:hilt-compiler:2.51.1' // Annotation Processor

    // Hilt と Navigation Compose の統合
    implementation 'androidx.hilt:hilt-navigation-compose:1.2.0' // 最新安定版を推奨

    // Jetpack Navigation for Compose
    implementation 'androidx.navigation:navigation-compose:2.7.7' // 最新安定版を確認

    // 他の依存関係...
}
```

### まとめ

`androidx.hilt:hilt-navigation-compose` は、Jetpack Compose と Navigation for Compose を Dagger Hilt と組み合わせて使用する際に、ViewModel のライフサイクル管理をナビゲーショングラフのスコープと連携させるためのライブラリです。特に、グラフスコープの ViewModel を共有したい場合に役立ちます。ただし、`androidx.navigation:navigation-compose` 自体の進化により、機能の重複や吸収があるため、使用前に確認することが重要です。
