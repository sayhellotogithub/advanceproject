ユーザーの操作や設定によって、アプリのアイコンを変更する

#### Flutterでアプリのアイコンを動的に変更できるか

| プラットフォーム                        | 動的アイコン変更       | 備考                                                 |
| --------------------------------------- | ---------------------- | ---------------------------------------------------- |
| **Android**                             | ✅ 可能（条件あり）     | ショートカットAPIまたは別アクティビティ経由で変更    |
| **iOS**                                 | ✅ 可能（iOS 10.3以降） | Appleが公式にサポートしてるが制限あり                |
| **Windows/macOS/Linux（デスクトップ）** | 🚫 基本的に不可         | OS側でアプリの実行中にアイコンを変更する仕組みがない |

### モバイル（Android / iOS）での動的アイコン変更

Flutterでは、公式には対応していないけど、**Platform Channels**を使えば、ネイティブコードで動的に変更可能！

#### ✅ iOS（iOS 10.3+）の方法（Objective-C / Swift）

- `UIApplication.shared.setAlternateIconName(...)` を使用する

参考コード（Swift）:

```swift
if UIApplication.shared.supportsAlternateIcons {
    UIApplication.shared.setAlternateIconName("icon2") { error in
        if let error = error {
            print("Error setting alternate icon: \(error)")
        }
    }
}
```

👉 Flutterでは、`MethodChannel` 経由でSwiftコードを呼び出す必要がある。

#### ✅ Android の場合（ショートカット経由）

- Androidでは**複数のActivityを用意し、それぞれに異なるアイコンを設定**
- `PackageManager` を使って、アクティビティの有効/無効を切り替えることで、アイコン変更を実現する

参考Javaコード：

```java
PackageManager pm = context.getPackageManager();
pm.setComponentEnabledSetting(
    new ComponentName(context, "com.example.NewIconAlias"),
    PackageManager.COMPONENT_ENABLED_STATE_ENABLED,
    PackageManager.DONT_KILL_APP);
```

👉 Flutterから `MethodChannel` を使ってこれを呼ぶ

#### 🖥 デスクトップ（Windows/macOS/Linux）は？

残念ながら、**アプリ実行中にアイコンを動的に変更するAPIが存在しない**ため、

- 実行ファイル（バイナリ）のアイコン変更は不可
- ショートカットのアイコンを**別に作って置き換える**などの手動対応しかない
