**`minSdkVersion` が 21** に設定されているために、`usesCleartextTraffic` 属性が **Android 5.0（API 21）と Android 5.1（API 22）では無視される**という注意です。

## 解説

- `usesCleartextTraffic` は Android **API 23（Android 6.0）以降**でしか効果がありません。
- そのため、`minSdkVersion` が 21 のままでは、**一部の古い端末でこの設定が効かない可能性がある**という意味です。

### 選択肢 1：**そのまま無視してOK**

- もしあなたのターゲットユーザーが **Android 6.0以上**であれば、そのままで問題ありません。
- この警告はビルドエラーではなく**Lint警告**なので、アプリは正常に動作します。

### 選択肢 2：**`minSdkVersion` を 23 に引き上げる**

```
android {
    defaultConfig {
        minSdk = 23
        ...
    }
}
```

- デメリット：Android 5.0 / 5.1（非常に古い端末）を切り捨てることになります。

## 補足：API 21/22で明示的にHTTPを禁止したい場合

API 21〜22では `usesCleartextTraffic` が無視されるので、代わりに **`network_security_config` を使って手動で制御**することができます。

### 1. `res/xml/network_security_config.xml`

```
<?xml version="1.0" encoding="utf-8"?>
<network-security-config>
    <base-config cleartextTrafficPermitted="false" />
</network-security-config>
```

### 2. `AndroidManifest.xml`

```
<application
    android:networkSecurityConfig="@xml/network_security_config"
    android:usesCleartextTraffic="false"  <!-- これは API23 以上用 -->
    ... >
```

これで **API 21〜22 でも HTTP を禁止**することができます。
