デバイスに対応させる方法

### **1. `MediaQuery` を使って画面サイズに応じたレイアウトを実現する**

`MediaQuery` を使用すると、デバイスの画面サイズやピクセル密度を取得できます：

```dart
import 'package:flutter/material.dart';

class ResponsiveWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    var screenWidth = MediaQuery.of(context).size.width;
    var screenHeight = MediaQuery.of(context).size.height;

    return Scaffold(
      body: Center(
        child: Container(
          width: screenWidth * 0.8,
          height: screenHeight * 0.5,
          color: Colors.blue,
          child: Center(child: Text('レスポンシブデザイン')),
        ),
      ),
    );
  }
}
```

👉 **ポイント**：画面サイズに基づいてコンテンツを柔軟に調整可能。

### **2. `LayoutBuilder` を使って親要素のサイズに応じたレイアウトを作る**

`LayoutBuilder` を使うと、親ウィジェットのサイズに基づいたレイアウトを構築できます：

```dart
import 'package:flutter/material.dart';

class ResponsiveLayout extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: LayoutBuilder(
        builder: (context, constraints) {
          if (constraints.maxWidth < 600) {
            return Center(child: Text('スマホレイアウト'));
          } else {
            return Center(child: Text('タブレットレイアウト'));
          }
        },
      ),
    );
  }
}
```

👉 **ポイント**：コンポーネント単位でレスポンシブ対応ができる。

### 📡 **3. ブレイクポイントを定義してデバイスに応じたレイアウトを調整する**

ブレイクポイントを定義することで、明確にスマホ・タブレット・PCなどを判別できます：

```dart
class Responsive {
  static bool isMobile(BuildContext context) =>
      MediaQuery.of(context).size.width < 600;

  static bool isTablet(BuildContext context) =>
      MediaQuery.of(context).size.width >= 600 &&
      MediaQuery.of(context).size.width < 1200;

  static bool isDesktop(BuildContext context) =>
      MediaQuery.of(context).size.width >= 1200;
}
```

👉 **ポイント**：条件分岐が明確になるため、複雑なUIにも対応可能。

### 📐 **4. `FittedBox` と `AspectRatio` でサイズ調整する**

- **FittedBox** は子ウィジェットを親ウィジェットに合わせて縮小・拡大します：

```dart
FittedBox(
  child: Text('自動調整テキスト'),
)
```

- **AspectRatio** は縦横比を維持してサイズを調整します：

```dart
AspectRatio(
  aspectRatio: 16 / 9,
  child: Container(color: Colors.red),
)
```

👉 **ポイント**：画像や動画など、比率を維持したい場合に便利。

### 🎨 **5. `flutter_screenutil` を使ってピクセル単位での適応を行う**

デバイスごとの解像度差を吸収したい場合は `flutter_screenutil` が役立ちます：

**インストール：**

```dart
dependencies:
  flutter_screenutil: ^5.0.0
```

**使用方法：**

```
import 'package:flutter_screenutil/flutter_screenutil.dart';

void main() {
  runApp(ScreenUtilInit(
    designSize: Size(375, 812), // デザインの基準サイズ
    minTextAdapt: true,
    builder: () => MyApp(),
  ));
}

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        body: Container(
          width: 100.w, // 幅を自動調整
          height: 50.h, // 高さを自動調整
          child: Text(
            '自動調整テキスト',
            style: TextStyle(fontSize: 16.sp), // フォントサイズも調整
          ),
        ),
      ),
    );
  }
}
```

👉 **ポイント**：デザインカンプ通りに細かくサイズを調整したい時に最適。

### ✅ **6. 実機テストで最終確認する**

最終的には、実際のデバイスでテストすることが重要です：

- **Android Studio** でエミュレーターのサイズを変更して確認
- `flutter run --release` を使って実機でパフォーマンスチェック
- 複数のデバイス（スマホ・タブレットなど）で実際に動作確認
