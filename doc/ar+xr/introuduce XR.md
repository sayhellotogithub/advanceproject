2025年5月の Google I/O で発表された **「Android XR」** と **スマートグラス関連技術**は、Google が**拡張現実（XR）プラットフォーム**に本格参入することを示す大きな一歩でした。

## Android XRとは？

**Android XR** は、Google が新たに開発している **拡張現実（AR + VR = XR）向けの Android 派生プラットフォーム**です。

| 特徴                  | 内容                                                       |
| --------------------- | ---------------------------------------------------------- |
| 🌐 クロスデバイス対応  | スマートフォン、スマートグラス、ヘッドセットに対応         |
| 🧠 Gemini AI搭載       | カメラ・音声・環境認識を統合したリアルタイムAIアシスタント |
| 🔧 Android開発環境連携 | Android Studio + Jetpackライブラリで開発可能               |
| 🤝 パートナー          | Samsung、Qualcomm、XREAL などと連携中                      |

## スマートグラス向け機能（Google + パートナー）

### 1. 📷 カメラ視界との連携（Live Vision）

- スマートグラスのカメラが見る世界を、Gemini AIがリアルタイムで理解。
- **翻訳・案内・認識**などを即時に提示。

### 2. 🗣️ 音声・視線操作対応

- 音声コマンド + 視線追跡による**ハンズフリー操作**が基本。
- 例：「あのビルは何？」「あの人にナビして」など。

### 3. 🌍 空間アンカーとUI

- 目の前の空間に情報や操作UIを「浮かべる」ことができる。
- Google Mapsやナビ連携も視界上に直接表示可能。

## 現在の入手性・状況

- Google純正XRグラスはまだ一般販売されていません（プロトタイプ段階）。
- XREAL（旧Nreal）や Samsung の製品と連携した開発が中心。
- SDKやサンプルコードは、**近いうちに公開予定**（Google I/O ではデモのみ）
