Dart Code Metrics 是一个用于分析 Dart 和 Flutter 代码质量的工具包。它帮助开发者检查代码中的潜在问题、复杂度过高的部分、不符合规范的命名等，是提升代码质量、可维护性和团队协作的一大利器。

**Dart Code Metrics** 项目在 2024 年已不再由原作者积极维护。

### 主要功能（Features）

1. **Metrics（度量指标）**：
   - Cyclomatic Complexity（圈复杂度）
   - Number of Arguments
   - Lines of Code
   - Nesting Level（嵌套层级）
   - Number of Methods in class
   - 类/函数的长度等
2. **Rules（代码检查规则）**：
   - 命名规范（如避免单字符变量名）
   - 避免重复代码
   - 避免深层嵌套
   - 检查是否遵守 SOLID 原则
   - 不推荐使用某些 Flutter 的构造方式等
3. **Anti-patterns（反模式识别）**：
   - 神对象（God Object）
   - 过度耦合
   - 冗余逻辑等

### 如何使用 Dart Code Metrics

#### 1. 安装

在你的项目的 `pubspec.yaml` 中添加：

```
dev_dependencies:
  dart_code_metrics: ^5.0.0
```

然后执行：

```
bash


复制编辑
flutter pub get
```

#### 2. 创建配置文件

在项目根目录创建 `.dart_code_metrics.yaml`：

```
yaml


复制编辑
metrics:
  cyclomatic-complexity: 20
  number-of-arguments: 4
  maximum-nesting-level: 5
  lines-of-code: 50
  number-of-methods: 10
  weight-of-class: 0.33

rules:
  - prefer-trailing-comma
  - no-equal-then-else
  - avoid-nested-conditional-expressions
  - avoid-returning-widgets
  - member-ordering

anti-patterns:
  - long-method
  - long-parameter-list
```

#### 3. 运行分析

```
bash


复制编辑
dart run dart_code_metrics:metrics analyze lib
```

或者（如果使用 Flutter）：

```
bash


复制编辑
flutter pub run dart_code_metrics:metrics analyze lib
```
